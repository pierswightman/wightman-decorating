WIGHTMAN DECORATING – JOB MANAGER
==================================

This is the first working prototype of your iPad job manager.

WHAT IT DOES
- Stores customer and job records in this browser on the iPad.
- Calculates decorating and floor sanding estimates.
- Uses £30/m² as the default floor sanding rate and £250 minimum.
- Tracks estimated costs, contribution and margin.
- Exports and imports a JSON backup.

IMPORTANT
This package must be placed on a secure HTTPS website before it can be installed
as a Home Screen web app. Opening index.html directly from Files is useful for
testing but does not provide the full installable/offline app behaviour.

HOW TO PUT IT ON YOUR IPAD
1. Upload the contents of this folder to a static HTTPS host (for example,
   a private GitHub Pages site or another web host).
2. Open the resulting HTTPS address in Safari on the iPad.
3. Tap Share, then Add to Home Screen.
4. Enable "Open as Web App" if that option appears, then tap Add.
5. Open the new Home Screen icon.

DATA AND BACKUPS
Records are stored locally in Safari's website storage on this iPad. They are
not automatically synchronised. Use Backup > Export backup regularly and keep
the JSON file in iCloud Drive or another safe location. Do not clear Safari
website data without first exporting a backup.

This is an early prototype, not yet a finished accounting or invoicing system.
Check all estimates before sending a customer quotation.
