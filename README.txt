WIGHTMAN DECORATING — VERSION 3

This is a room-by-room quotation and job-costing prototype.

Features:
- Customer and property records
- Add unlimited rooms and areas
- Select walls, ceilings, woodwork, doors, windows, staircases, radiators, cupboards, wallpaper, repairs and extra preparation
- Enter estimated hours, materials and other costs by room
- Add separate floor sanding areas priced per square metre, with editable rate and minimum charge
- Adjustable decorating charge and internal labour cost
- Quotation preview and print / Save PDF
- Actual labour, materials, expenses and final charge comparison
- Saved jobs and JSON backup / restore
- Uses the existing localStorage key wightmanDecoratingJobsV1 so existing saved jobs remain in the browser when the site files are replaced

IMPORTANT:
1. Export a backup from the current app before replacing website files.
2. Upload index.html, manifest.json and sw.js to the root of the existing GitHub Pages repository, replacing the old files.
3. Open the site in Safari and refresh. If an older cached version remains, close the app/tab and reopen; you may need to clear website data for this site only.
4. Data stays in the browser on this iPad. It is not synced to GitHub or cloud storage. Export backups regularly.
5. This is a prototype. Test calculations and quotation wording before relying on it for live customer quotes.
